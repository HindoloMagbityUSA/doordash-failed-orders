# DoorDash: Insights from Failed Orders

An in-progress portfolio project based on the StrataScratch “Insights from Failed Orders” case study.

## Objective

Explore unsuccessful orders and communicate findings through a reproducible Python analysis.

## Status

Project setup and initial dataset familiarization. Analysis and findings will be added as the project progresses.

## Structure

- `notebooks/analysis.ipynb`: project notebook; analysis has not started.
- `data/`: local source datasets, excluded from version control.

## Data

The case study provides `data_orders.csv` and `data_offers.csv`. Obtain these files from StrataScratch and place them in `data/` to work with the notebook. Source datasets are not redistributed in this repository.

## Working with the notebook

Open `notebooks/analysis.ipynb` in Jupyter or VS Code with a Python environment. Analytical dependencies and execution instructions will be documented as they are introduced.
